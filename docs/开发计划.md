# PDF 工具箱 — 开发计划

> 版本：1.0.0 | 更新：2026-06-09  
> 功能清单详见 [功能全景.md](功能全景.md)

## 一、项目现状

| 项 | 状态 |
|---|---|
| 定位 | PDF 多功能桌面工具箱（由压缩器升级中） |
| 技术栈 | Tauri 2 + Vite 6 + 原生 JS + Rust + lopdf |
| 已完成功能 | 工具箱全模块已上线 |
| 版本管理 | 已有 `.gitignore` |

## 二、开发原则

1. **先文档后开发**：每阶段写入本计划再动手
2. **小步迭代**：每阶段可独立交付验证
3. **共用基础设施**：拖放、loading、对话框、结果区复用
4. **lopdf 优先**：能用 lopdf 的不引入外部二进制

## 阶段 7：页面工具

**目标**：合并、拆分、提取、删除、旋转页面。

| 任务 | 说明 | 验收 |
|------|------|------|
| 7.1 `get_pdf_info` | 返回页数、文件大小 | 选文件后显示页数 |
| 7.2 `merge_pdfs` | 多 PDF 合并为一个 | 合并成功 |
| 7.3 `split_pdf` | 按范围 `1-3;4-6` 或每 N 页拆分 | 多文件输出 |
| 7.4 `extract_pages` | 提取 `1-5,8` 页 | 输出正确页数 |
| 7.5 `delete_pages` | 删除指定页 | 输出页数减少 |
| 7.6 `rotate_pages` | 90/180/270 旋转 | 旋转生效 |
| 7.7 页面工具 UI | `tools/pages.html` 操作切换表单 | 五种操作可用 |

**状态**：✅ 已完成
