# PDF 工具箱 v1.0.0 — 发布说明

## 下载与安装

### 方式一：安装程序（推荐）

1. 下载 `PDF Toolbox_1.0.0_x64-setup.exe`
2. 双击运行，按向导完成安装（默认安装到 `C:\Program Files\PDF Toolbox`，需管理员权限）
3. 从开始菜单「inkdot」文件夹或桌面快捷方式启动「PDF Toolbox」（窗口标题仍为「PDF 工具箱」）

### 方式二：绿色版（便携版）

1. 下载 `PDF工具箱-1.0.0-便携版.zip`
2. 解压到任意目录（路径尽量不要含特殊字符）
3. 运行 `pdf-compress.exe`
4. 详细说明见压缩包内 `用户手册.md` 或 [docs/用户手册.md](用户手册.md)

> 绿色版不会写入注册表，删除文件夹即可卸载。

| 项目 | 要求 |

## 功能一览

- **压缩**：减小 PDF 体积，支持批量
- **扫描增强**：图片重压缩、降分辨率、转灰度
- **格式转换**：图片↔PDF、PDF↔文本、Office→PDF、PDF 批量导出图片
- **页面工具**：合并、拆分、提取、删除、旋转、重排、插入、裁剪、去空白页等
- **水印版式**：文字/图片水印、页眉页脚（支持系统字体，中文水印可用）
- **安全隐私**：加密、解密、清除元数据
- **脱敏涂黑**：预览框选敏感区域，输出涂黑 PDF
- **预览信息**：文档预览、缩略图、元数据编辑

---

## 使用提示

1. **输出路径**：选择源文件后会自动填充同目录输出路径，文件名带功能后缀（如 `报告-水印.pdf`）
2. **拖放**：各工具页面支持将 PDF / 图片 / Office 文件拖入窗口
3. **中文水印**：在「水印版式 → 字体」中选择微软雅黑、宋体等系统字体
4. **Office 转换**：转换时会短暂启动对应 Office 程序，属正常现象
5. **处理完成**：结果以弹窗提示，可一键打开输出文件所在文件夹

---

## 已知限制

- 仅支持 Windows 桌面版（当前版本）
- 部分加密或结构异常的 PDF 可能无法处理
- Office 转 PDF 依赖本机 Office，未安装则该功能不可用
- 文本转 PDF 对复杂排版支持有限，适合纯文本场景
- 未签名安装包时，Windows 可能提示「未知发布者」，选择「仍要运行」即可

## 卸载

- **安装版**：设置 → 应用 → 已安装的应用 → 卸载「PDF 工具箱」
- **绿色版**：直接删除解压目录
